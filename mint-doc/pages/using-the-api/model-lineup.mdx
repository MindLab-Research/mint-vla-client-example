## Model Selection Recommendations

- **Latency-focused:** Use Instruction models
- **Intelligence-focused:** Use Hybrid or Reasoning models (chain-of-thought support)
- **Custom tasks:** Fine-tune Base models for your specific use case
- **Multimodal needs:** Use Vision models (T2) for image understanding
- **Robotics applications:** Use Pi0 (T2) for embodied AI tasks

## Model Categories

### By Training Type
- **Base** - Pre-trained foundation models
- **Instruction** - Fine-tuned for instruction following
- **Reasoning** - Optimized for chain-of-thought reasoning
- **Hybrid** - Combined capabilities
- **Vision** - Multimodal (text + image)
- **Robotics** - Embodied AI and robotics tasks

### By Architecture
- **Dense** - Traditional transformer architecture
- **MoE (Mixture of Experts)** - Sparse activation for efficiency

### By Size
- **Compact:** 1-4B parameters
- **Small:** 8B parameters
- **Medium:** 30B parameters
- **Large:** 70B+ parameters

## Cost Efficiency

MoE models offer superior cost-efficiency: pricing scales with **active parameters**, not total model size. For example, a 235B MoE model with 22B active parameters costs the same as a 22B dense model.

## 模型选择建议

- **延迟优先：** 使用指令模型
- **智能优先：** 使用混合或推理模型（支持思维链）
- **自定义任务：** 针对您的特定用例微调基础模型
- **多模态需求：** 使用视觉模型（T2）进行图像理解
- **机器人应用：** 使用 Pi0（T2）进行具身 AI 任务

## 模型分类

### 按训练类型
- **基础** - 预训练基础模型
- **指令** - 针对指令遵循进行微调
- **推理** - 针对思维链推理进行优化
- **混合** - 组合能力
- **视觉** - 多模态（文本 + 图像）
- **机器人** - 具身 AI 和机器人任务

### 按架构
- **稠密** - 传统 Transformer 架构
- **MoE（专家混合）** - 稀疏激活以提高效率

### 按规模
- **紧凑：** 1-4B 参数
- **小型：** 8B 参数
- **中型：** 30B 参数
- **大型：** 70B+ 参数

## 成本效率

MoE 模型提供更优的成本效率：定价按**活跃参数**计算，而非总模型大小。例如，具有 22B 活跃参数的 235B MoE 模型与 22B 稠密模型成本相同。
