# Installation

## Install from Source

Clone the repository and install in development mode:

```bash
git clone https://github.com/MindLab-Research/mindlab-toolkit.git
cd mindlab-toolkit
pip install -e .
```

## What's Included

The MinT Python SDK provides low-level operations including `forward_backward`, `sample`, `optim_step`, and `save_state` functionality.

## Authentication

API access requires setting up credentials:

1. Obtain an API key from the **Mind Lab team**
2. Set the `MINT_API_KEY` environment variable

```bash
export MINT_API_KEY=sk-mint-your-key-here
```

## Tinker Compatibility

MinT is fully API-compatible with [Tinker](https://tinker.thinkingmachines.ai). If you already have the `tinker` package installed, you can use it with MinT by setting environment variables:

```bash
export TINKER_BASE_URL=https://mint-alpha.macaron.im
export TINKER_API_KEY=<your-mint-api-key>
```

All code using `import tinker` will work with MinT without modification.

## Quickstart

For a hands-on tutorial, see the [mint-quickstart](https://github.com/MindLab-Research/mint-quickstart) repository which demonstrates SFT and RL training workflows.
