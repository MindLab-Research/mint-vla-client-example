# Installation

## Installation Command

The primary installation method is straightforward:

```bash
pip install tinker
```

## Components Included

The installation provides two main tools:

### 1. Python SDK

Offers low-level operations including `forward_backward`, `sample`, `optim_step`, and `save_state` functionality.

### 2. MinT CLI

Available as `tinker` command or via `python -m tinker`. It delivers management features comparable to the web console. Users can execute `tinker --help` to discover available options.

## Authentication

API access requires setting up credentials:

1. Generate an API key by contacting the **Mind Lab team**
2. Configure the `TINKER_API_KEY` environment variable with your generated key

This setup enables full access to MinT's training, sampling, and management capabilities.
